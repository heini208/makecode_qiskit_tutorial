# MakeCode MicroQiskit Tutorial

Interaktives deutschsprachiges MakeCode-Tutorial für die MicroQiskit-Erweiterung auf dem Calliope mini.

**Aktuelle Tutorial-Version: 0.0.7**

## Tutorial starten

https://makecode.calliope.cc/#tutorial:https://github.com/heini208/makecode_qiskit_tutorial/tutorial-v0-0-7

Im ersten Dialog muss **Tutorial-Version 0.0.7, Stand 12.09.2026** stehen.

Die MicroQiskit-Erweiterung wird automatisch geladen. Aktuell ist **v0.1.5** eingebunden.

In Version 0.0.7 sind Gate-Erklärung und Übung getrennt: Die Animation wird automatisch in einem sichtbaren Dialog gezeigt. Im anschließenden Übungsschritt stehen alle Arbeitsanweisungen und das erwartete Ergebnis direkt im Haupttext. Nur die fertige Blocklösung liegt hinter der Glühbirne.

Extension: https://github.com/heini208/makecode-qiskit
