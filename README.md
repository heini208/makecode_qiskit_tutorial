# MakeCode MicroQiskit Tutorial

Interaktives deutschsprachiges MakeCode-Tutorial für die MicroQiskit-Erweiterung auf dem Calliope mini.

**Aktuelle Tutorial-Version: 0.0.6**

## Tutorial starten

https://makecode.calliope.cc/#tutorial:https://github.com/heini208/makecode_qiskit_tutorial/tutorial-v0-0-6

Im ersten Dialog muss **Tutorial-Version 0.0.6, Stand 12.09.2026** stehen.

Die MicroQiskit-Erweiterung wird vom Tutorial automatisch geladen. Aktuell ist die Extension-Version **v0.1.5** eingebunden.

Die Gate-Schritte 5 bis 13 verwenden jetzt ein einheitliches Muster: Gate im Dropdown auswählen, Programm ausführen und direkt prüfen, welches Messergebnis zu erwarten ist.

Für Tutorial 0.0.6 werden erneut versionierte GIF-Dateinamen verwendet, damit keine alten fehlgeschlagenen Bildabrufe aus einem Cache übernommen werden.
