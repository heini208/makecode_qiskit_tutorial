# MakeCode MicroQiskit Tutorial

Interaktives deutschsprachiges MakeCode-Tutorial für die MicroQiskit-Erweiterung auf dem Calliope mini.

## Tutorial starten

https://makecode.calliope.cc/#tutorial:https://github.com/heini208/makecode_qiskit_tutorial/tutorial

Das Tutorial liegt ausschließlich in `tutorial.md`. Diese Datei ist immer die aktuelle Fassung.

Die Bloch-Kugel-Animationen liegen unter `images/` ohne Versionspräfix. Die unversionierten GIF-Dateien sind ebenfalls immer die aktuelle Fassung.

Die MicroQiskit-Erweiterung wird vom Tutorial automatisch geladen.

## Dateien

- `tutorial.md`: aktueller Tutorial-Inhalt
- `images/`: aktuelle Bloch-Kugel-Animationen
- `pxt.json`: MakeCode-Projektkonfiguration
- `main.ts`: bleibt absichtlich leer

Extension: https://github.com/heini208/makecode-qiskit
