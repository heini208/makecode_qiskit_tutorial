# MakeCode MicroQiskit Tutorial

Interaktives deutschsprachiges MakeCode-Tutorial für die MicroQiskit-Erweiterung auf dem Calliope mini.

**Aktuelle Tutorial-Version: 0.0.8**

## Tutorial starten

https://makecode.calliope.cc/#tutorial:https://github.com/heini208/makecode_qiskit_tutorial/tutorial-v0-0-8

Im ersten Dialog muss **Tutorial-Version 0.0.8, Stand 12.09.2026** stehen.

Version 0.0.8 verwendet MakeCodes `@explicitHints true`. Dadurch bleiben Erklärungen, GIFs und Arbeitsanweisungen zusammen im normalen Tutorial-Schritt sichtbar. Nur die fertige Blocklösung ist als `tutorialhint` hinter der Glühbirne abgelegt.

Die MicroQiskit-Erweiterung wird automatisch geladen. Aktuell ist **v0.1.5** eingebunden.

Extension: https://github.com/heini208/makecode-qiskit
